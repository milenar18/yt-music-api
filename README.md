# 🎧 YouTube Music API

API feita com FastAPI para buscar e tocar músicas do YouTube.

## 🚀 Funcionalidades

- 🔎 Buscar músicas
- 🎧 Streaming de áudio
- 🌐 Interface web

## 🛠 Tecnologias

- FastAPI
- yt-dlp
- HTML + JavaScript

## ▶️ Como rodar

```bash
pip install -r requirements.txt
uvicorn app.main:app --reload
